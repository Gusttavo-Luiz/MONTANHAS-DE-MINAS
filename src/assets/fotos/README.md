# Fotografias oficiais do Restaurante Montanhas de Minas

Coloque aqui **somente fotografias reais do restaurante**, com o nome exato
listado abaixo. Nunca use imagens de bancos de imagem ou de outros
estabelecimentos como se fossem do Montanhas de Minas. JPG de boa qualidade,
2000 px ou mais no lado maior, sem marca d'água. O build gera AVIF/WebP
redimensionados e com carregamento tardio automaticamente.

Enquanto um arquivo não existir, o site mostra uma ilustração no lugar (e, na
primeira dobra, a ilustração das serras ao entardecer).

| Arquivo | Onde aparece |
| --- | --- |
| `hero.jpg` | Primeira dobra (foto horizontal ampla: fachada, área externa ou mesa posta) |
| `essencia-01.jpg` | Nossa essência — foto principal (vertical) |
| `essencia-02.jpg` | Nossa essência — detalhe de um prato (quadrada) |
| `cardapio-mineira.jpg` | Cardápio — Comida mineira e brasileira |
| `cardapio-carnes.jpg` | Cardápio — Carnes e churrasco |
| `cardapio-pizzas.jpg` | Cardápio — Pizzas |
| `cardapio-porcoes.jpg` | Cardápio — Peixes e porções |
| `cardapio-bebidas.jpg` | Cardápio — Bebidas |
| `ambiente-fachada.jpg` | Ambiente — destaque do mosaico (fachada e área externa) |
| `ambiente-interno.jpg` | Ambiente — ambiente interno (vertical) |
| `ambiente-mesas.jpg` | Ambiente — mesas e convivência |
| `ambiente-pratos.jpg` | Ambiente — pratos e detalhes |
| `ambiente-natureza.jpg` | Ambiente — natureza ao redor (horizontal larga) |
| `ambiente-area-externa.jpg` | Ambiente — espaço ao ar livre (horizontal larga) |
| `ambiente-infantil.jpg` | Ambiente — área infantil (*só aparece depois de confirmada*) |
| `ambiente-musica.jpg` | Ambiente — música ao vivo (*só com registro autorizado*) |

Para a área infantil e a música ao vivo, além de enviar a foto, mude
`confirmed: false` para `confirmed: true` em `src/content/photos.ts`.
